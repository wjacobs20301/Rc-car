# Portenta firmware (secondary / legacy)

This folder targets **Arduino Portenta H7 + Vision Shield (Himax)**.

The **active** car hardware for this continuation is the **Seeed XIAO ESP32S3 Sense** — use:

```text
cursor-continuation/firmware_xiao/TrackFollowCar/
```

Keep this Portenta sketch only if you still have Portenta hardware.
